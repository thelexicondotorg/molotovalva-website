# Fonts Directory

Place your custom **Platelet** font file(s) here.

Supported file names and formats:
- `Platelet.woff2` *(Recommended)*
- `Platelet.woff`
- `Platelet.otf`
- `Platelet.ttf`

Optional Regular weight (400):
- `Platelet-Regular.woff2` / `Platelet-Regular.otf` / `Platelet-Regular.ttf`

Once placed here, Vite will automatically serve the font at `/fonts/Platelet...` and `src/styles/main.css` will apply it to all terminal elements and prompts immediately.
